วิธีการนำไฟล์นี้ขึ้นใช้งานบน GitHub Pages

  1. สร้าง Repository ใหม่บน GitHub (ตั้งชื่อ เช่น covid19-dashboard)
  2. บันทึกไฟล์โค้ดนี้ทั้งหมดลงในคอมพิวเตอร์ของคุณ ตั้งชื่อไฟล์เป็น index.html
  3. อัปโหลดไฟล์ index.html ขึ้นสู่ Repository ที่สร้างไว้ (Add file -> Upload files)
  4. ไปที่เมนู Settings > Pages ของ Repository นั้น
  5. ในหัวข้อ Build and deployment > เลือก Branch เป็น main (หรือ master) แล้วกด Save
  6. รอประมาณ 1-2 นาที ระบบจะสร้างลิงก์เว็บไซต์พร้อมใช้งานจริงผ่านอินเทอร์เน็ตทันที
